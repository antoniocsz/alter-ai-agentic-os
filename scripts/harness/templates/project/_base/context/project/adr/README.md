## Ciclo de vida

- `proposed` — em discussão; ainda não vale como regra.
- `accepted` — decisão vigente.
- `superseded` — substituída por um ADR mais novo (aponte no campo "Superseded by").
- `deprecated` — não vale mais, sem substituta.

Regras:

1. Decisão nova = novo arquivo `ADR-XXX-<slug>.md` copiado do template, status `accepted`.
2. Substituir = criar o novo ADR e marcar o antigo como `superseded by ADR-YYY`.
3. Nunca apague ADRs antigas: o histórico importa.
