# Codex — prompts do harness

Os prompts em `.codex/prompts/` são templates para o CLI do Codex. Copie-os para o seu
diretório de prompts do Codex (normalmente `~/.codex/prompts/`) para usá-los como `/status`,
`/recall` e `/handoff`.

O protocolo canônico continua em `AGENTS.md` (lido nativamente pelo Codex) e o estado vive no
próprio repositório (`context/`, `tasks/`, `.harness/`) — trocar de tool não perde trabalho.
